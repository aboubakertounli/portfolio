# Portfolio — TOUNLI Aboubaker

Static site (Astro + Tailwind). One codebase, French and English routes (`/fr/`, `/en/`). The language toggle stores a preference; first visit follows the browser language and falls back to French.

```bash
npm ci
npm run dev
```

Deploy: import this GitHub repo on [Vercel](https://vercel.com). Framework preset: Astro.

The DevSecOps case study links to:

- https://github.com/aboubakertounli/DevSecOps-x-GitOps
- https://github.com/aboubakertounli/DevSecOps-x-GitOps-gitops
